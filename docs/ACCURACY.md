# FATHOM 工业准确率与质量门禁

“99% 准确率”只对已认证业务域和明确评测集负责，不对无限开放问题做虚假承诺。

## 指标定义

- 语义计划准确率：对象、指标、时间、关系和条件全部正确的计划数 / 可回答黄金问题数，发布门槛 `>= 99%`。
- 确定性计算一致率：FATHOM 结果与业务 Owner 确认的基准 SQL/MetricFlow 结果一致率，门槛 `100%`。
- 权限命中率：越权问题被阻断且合法问题不被误拦的比例，门槛 `100%`。
- 可执行成功率：合法计划在资源预算内完成的比例，门槛 `>= 99.5%`。
- 证据完整率：结果包含语义版本、数据时间、过滤范围、来源与 trace 的比例，门槛 `100%`。

## 防错路径

1. Acquire：识别对象、范围、身份与时间，歧义时澄清。
2. Build：只从已发布本体和指标构建关系与计算计划。
3. Policy：应用对象、字段、角色、工具和资源预算约束。
4. Compute：使用参数化模板或确定性编译器执行，不运行模型自由生成的任意 SQL。
5. Verify：对单位、空值、时间、新鲜度、总分关系和基准结果进行质检。
6. Explain：返回证据和相关/因果边界；不确定时明确降级或拒答。

当前自动化基线包含 100 条制造执行问法，测试会阻止语义计划准确率低于 99% 的版本合入。真实客户上线必须用客户确认的对象、权限、指标和问题集替换或扩充基线。
