# 小白可用的渐进式建设路径

## 默认流程

```text
连接数据 → 选择场景 → 提交常见问题 → 自动 Scaffold
→ 确认冲突 → 黄金问题评测 → 发布 → 使用中持续提案
```

普通业务用户只需要理解业务对象、指标、规则和问题。OWL、RDF、MDL、SQL、Join Graph 与 YAML 放在高级工程视图。

## 四级成熟度

- L0：数据连接、业务词典和少量指标即可开始问数。
- L1：认证一个有限领域 ONN，并通过至少 99% 黄金问题门槛。
- L2：建立 ERP、MES、OT、组织和空间的跨域关系。
- L3：接入实时事件、Case、审批与运营动作闭环。

## 自进化边界

当前系统记录历史查询与执行结果，并可从 Schema、已有语义模型和业务输入生成候选。候选由用户点击发布，系统自动执行影响检查和回归评测；生产语义绝不静默修改。失败问题自动聚类、Schema 漂移监听和基于反馈的持续提案仍属于后续增强能力。
