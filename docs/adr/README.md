# FATHOM Architecture Decision Records

本目录保存 FATHOM 的架构决策。当前基线决策及其上下文、后果和替代方案已记录在根目录的《FATHOM-规划方案.md》第 13 节；进入实施阶段后，每条决策应拆为独立 ADR，并在状态变化时新增 superseding ADR，不覆盖历史。

建议编号：

- ADR-001：模块化单体与异步 Worker
- ADR-002：FATHOM Contract 作为唯一语义事实源
- ADR-003：SQLite-first 与 PostgreSQL 可升级存储
- ADR-004：联邦查询与源端下推
- ADR-005：Dify 作为消费者
- ADR-006：受控自进化
