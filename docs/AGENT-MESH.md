# 智能体网络

FATHOM 不把智能体等同于 Prompt。每个智能体声明职责、输入输出、可用工具、模型角色、权限和资源预算；编排器按任务选择最短可信链路。

## 五层十二个内置智能体

- 调度：任务编排智能体。
- 认知：数据探查、本体映射、指标构建。
- 推理：问数规划、探索分析、跨模态理解。
- 执行：受控计算、实时上下文、动作桥接。
- 治理：证据与权限、演化学习。

它们共享 FathomPlan、ONN 六元对象空间、身份范围、语义版本、证据和 trace_id。受控计算、实时读取和权限判断无需 LLM；规划、抽取、解释和视觉才绑定模型角色。

## 默认网络

### 可信问数

任务编排 → 问数规划 → 证据与权限 → 受控计算 → 证据与权限。

### 小白建模

数据探查 → 本体映射 → 指标构建 → 演化学习。产出只进入候选区，通过黄金问题、影响分析和人工审批后发布。

### 实时诊断

实时上下文 → 探索分析 → 证据与权限 → 动作桥接。默认输出建议；写工单、发指令等外部副作用要求确认和幂等键。

## 与上层 Agent 平台的关系

FATHOM 内置智能体负责企业语义和可信执行；Dify、其他工作流平台或自研 Agent 负责编排用户体验、通用知识和跨系统工作流。两者通过 Agent Access Gateway 协作，上层平台不能绕过 FATHOM 直接取得数据源凭证。
