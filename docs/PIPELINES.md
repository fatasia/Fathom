# 轻量数据管道与 Python 扩展

FATHOM 提供用于语义建设的 ELT-lite，不替代企业现有调度和大数据开发平台。

## 无代码管道

内置步骤包括字段重命名、类型转换、过滤、派生、去重、质量检查和 ONN 映射。定义保存为 YAML/JSON，预览与本地小数据使用 DuckDB，生产大查询优先下推源数据库。

## 外部编排

现有企业调度与数据开发平台继续负责复杂依赖、大规模同步和生产调度。FATHOM 保存语义映射、质量门禁、运行 trace 与版本关联。

## Python 扩展

Python 不作为普通用户的任意代码执行器。专家提交扩展 Manifest 和锁定依赖，平台在隔离 Worker 中执行：

- 默认无网络访问；
- 只读输入，只允许写任务临时目录；
- 限制 CPU、内存、运行时间和输出体积；
- 依赖哈希、代码版本和审批记录进入审计；
- 测试和黄金问题通过后才能发布为 Agent Tool。

当前 API 已提供管道与 Python Extension Manifest 的结构和安全校验，实际隔离执行器应根据 Windows Service 或 Linux systemd 的部署环境选择对应进程沙箱。
